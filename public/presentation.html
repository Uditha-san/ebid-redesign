UX / UI Application Pitch

Problem Identification


  • Intrusive Modals: Screen-blocking popups interrupted tasks.
  • Poor Visual Hierarchy: "Walls of text" made parsing difficult.
  • Complex Onboarding: "Sell Item" lacked progressive steps.
  • Outdated Architecture: Failed to use standard UI/UX patterns.

HCI Violations Identified

Miller’s Law 📉

The original interface presented massive, unstructured text lists, causing Working Memory Overload.

Hick’s Law 🌀

Dense drop-down elements paralyzed users through unstructured Choice Overload.

Homepage Redesign Old Format

[ Screenshot of Old eCommerce Layout ]
  • Unclear Primary Call-to-Action.
  • Categories relied on text-scanning.
  • Value Propositions (e.g. Zero Fees) were buried.

Homepage Redesign Optimized

Prioritizing discovery with a centered search & hero value prop.

Category Navigation Cognitive Load


“Everything felt identical. The interface lacked distinct visual groupings or icons, making it difficult to scan for correct departments.”

Violation of Gestalt Grouping

Category Navigation Gestalt UI

  • Added dynamic grid-based "Shop Top Categories".
  • Distinct iconography reduces text-parsing time.
  • Jakob's Law: Users are familiar with icon-grids from Amazon/Ebay.
[ Screenshot of Category Cards ]

Utility UI Blocking Flow


The Issue: Checking the cart or alerts spawned massive centered popups.

This completely blocked the store, breaking spatial context and stopping users from shopping.

Utility UI Slide Drawers

Spatial Consistency

Slide-out trays anchor users to their original tab.

Fitts's Law

Target keys grouped predictably to the top-right corner.

[ Screenshot of the Side Drawer over blurred background ]

Seller Onboarding Overload

Users were bombarded with form fields all at once, creating confusion about fees, item conditions, and listing options.

Seller Onboarding Chunking


We broke the complex process into a simple progressive 2-step wizard.

[ Screenshot of new Sell Item Form (Photo Drag-Drop area) ]

Seller Onboarding Hick's Law

[ Screenshot of the $0.00 Inline Fee Box ]
  • Calculated transparent fee structure upfront.
  • Condition variables simplified to pill buttons rather than deep dropdowns.
